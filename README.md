
# BMI Calculator

A simple Python-based BMI Calculator developed as part of the Oasis Infobyte Internship.

## Features

* Takes weight as input in kilograms.
* Takes height as input in meters.
* Calculates BMI using the standard BMI formula.
* Displays the calculated BMI up to two decimal places.
* Categorizes the BMI result.

## Technologies Used

* Python

## How to Run

1. Make sure Python is installed.
2. Open the Python file in VS Code.
3. Run the program.
4. Enter your weight in kilograms.
5. Enter your height in meters.
6. The program displays your BMI and category.

## BMI Formula

BMI = Weight (kg) / Height² (m)
